# صدای فارسی آفلاین

در پنجرهٔ چت، «میکروفون — صحبت کن» یک نوبت کوتاه گفتار فارسی را می‌گیرد.
میکروفون دائماً باز نیست. متن تشخیص‌داده‌شده به همان IranRuntime.handle فرستاده می‌شود؛
حافظه و تصمیم‌گیری همان دستیار پیوسته هستند. گزینهٔ «خواندن پاسخ با صدای فارسی»
پاسخ نهایی را در worker با Piper تولید و روی Windows پخش می‌کند.
دکمهٔ توقف، دریافت و پخش را لغو می‌کند و متن دیررس ارسال نمی‌شود.
بستن برنامه تا پایان امن worker صبر می‌کند.

## نصب یک‌باره روی دستگاه

وابستگی‌ها: requirements-jarvis.txt.
فایل voice.local.example.json را با مسیر مدل‌های واقعاً نصب‌شده به voice.local.json کپی کنید.
voice.local.json و models/voice در Git ثبت نمی‌شوند. برنامه هیچ مدل یا فایلی دانلود نمی‌کند.

منابع رسمی فایل‌های پیشنهادی:
- https://alphacephei.com/vosk/models/vosk-model-small-fa-0.42.zip
- https://github.com/rhasspy/piper/releases/download/2023.11.14-2/piper_windows_amd64.zip
- https://huggingface.co/rhasspy/piper-voices/tree/main/fa/fa_IR/amir/medium

فایل ONNX همراه با فایل هم‌نام .onnx.json لازم است. مدل گفتار را از ZIP استخراج کنید.
اجزای Piper باید کنار piper.exe باقی بمانند. فایل‌های مجوز و model card را حفظ کنید.

پس از نصب، تشخیص و تولید صدا روی دستگاه انجام می‌شوند و برای آن‌ها API key یا اینترنت لازم نیست.
اینترنت پروژه و مسیر یادگیری آنلاین از صدا مستقل‌اند. گفتار خام در این مسیر ذخیره یا ارسال نمی‌شود.

## پذیرش

آزمون‌های CI از transportهای ساختگی برای کنترل مسیر، UTF-8، لغو، cleanup و پاسخ‌گویی GUI استفاده می‌کنند؛
آن‌ها کیفیت شنیداری یا دقت مدل واقعی را اثبات نمی‌کنند.
روی دستگاه، گفتار فارسی، متن تشخیص، پخش پاسخ، توقف و restart بررسی شوند.
موفقیت فراخوانی playback اثبات شنیده‌شدن یا کیفیت تلفظ نیست.

تنظیم record_seconds بین ۱ و ۱۵ ثانیه محدود می‌شود. پیش‌فرض ۵ ثانیه است.
اگر مدل یا وابستگی موجود نباشد، دکمهٔ صدا غیرفعال است و حالت متنی همچنان کار می‌کند.

روی Windows اگر نام پوشهٔ پروژه فارسی است، مدل‌ها و برنامهٔ Piper را در مسیری با نام انگلیسی مانند %LOCALAPPDATA%/IRAN/voice نگه دارید و مسیر کامل را در voice.local.json بنویسید؛ برخی کتابخانه‌های بومی مسیر Unicode را نمی‌خوانند. مسیر دادهٔ مکالمه تغییری نمی‌کند.
